# Vestigia — Game

Videojuego desarrollado en Unity y C# como parte del proyecto Vestigia.

## Requisitos

- **Unity 6.5** (`6000.5.9f1`), versión utilizada para el desarrollo.
- Unity Hub para gestionar e importar el proyecto.

## Assets externos

Antes de abrir las escenas, instala los siguientes paquetes desde la Unity Asset Store:

| Asset | Descripción | Enlace |
|---|---|---|
| AQUIS - Water Toon Shader (Orto & Perspective) | Shader estilizado para materiales de agua. | [Abrir en Unity Asset Store](https://assetstore.unity.com/packages/vfx/shaders/aquis-water-toon-shader-orto-perspective-370678) |
| Space Skyboxes 4K Free | Colección de fondos y skyboxes espaciales en alta resolución. | [Abrir en Unity Asset Store](https://marketplace.unity.com/packages/2d/textures-materials/sky/space-skyboxes-4k-free-354458) |

### Instalación

1. Abre el enlace de cada asset e inicia sesión con tu cuenta de Unity.
2. Añade los paquetes a tu biblioteca e impórtalos al proyecto mediante Unity Hub o el Editor de Unity.
3. Abre el proyecto desde la carpeta `game/`.
4. Si alguna escena muestra materiales o fondos faltantes, verifica que los paquetes se hayan importado correctamente.

**Nota:** Los assets externos no se incluyen necesariamente en el repositorio. Cada colaborador debe obtenerlos desde su fuente original y respetar sus respectivas licencias.

## Estructura

- `Assets/`: escenas, scripts, materiales, prefabs y recursos del juego.
- `Packages/`: dependencias y paquetes de Unity.
- `ProjectSettings/`: configuración del proyecto.
